# TS Practice 1

Практическая работа по TypeScript — базовые типы, функции, мини-проект «Библиотека».

## Запуск

```
npm install
npx tsc
node dist/index.js
```

## Структура

- `src/index.ts` — все задания: базовые типы, функции, вызовы, библиотека
- `src/library.ts` — тип `Book` и функции для работы с книгами
- `tsconfig.json` — конфиг компиляции (esnext, nodenext, strict)

## Ошибки компилятора (часть 5)

| Код | Ошибка | Причина и исправление |
| --- | ------ | --------------------- |
| A | Type 'string' is not assignable to type 'number'. | Переменная выведена как number, а ей присваивают строку. Исправление: присваивать число или поменять тип на number \| string. |
| B | Expected 2 arguments, but got 1. | Функция требует два аргумента, передали один. Исправление: передавать оба или сделать второй параметр со значением по умолчанию. |
| C | Type 'null' is not assignable to type 'string'. | null не входит в тип string при strictNullChecks. Исправление: string \| null или пустая строка. |
| D | A function whose declared type is neither 'void' nor 'any' must return a value. | Функция объявлена с типом string, но ничего не возвращает. Исправление: добавить return или поменять тип на void. |

## Вопросы для самопроверки

1. **Что такое статическая типизация и какие преимущества она даёт?**
   Тип переменной известен на этапе компиляции и проверяется до запуска программы. Преимущества: ошибки ловятся раньше, код самодокументируется, автодополнение в редакторе работает лучше.

2. **Что такое вывод типов? Когда лучше указывать аннотацию явно?**
   Компилятор сам определяет тип по начальному значению. Явная аннотация нужна, когда тип сложный (функции, объекты, объединения) или когда без неё непонятно.

3. **За что отвечает "strict": true в tsconfig.json?**
   Включает все строгие проверки: strictNullChecks (запрет null/undefined в чужих типах), noImplicitAny (запрет неявного any) и другие.

4. **Как скомпилировать проект и запустить результат?**
   `npx tsc` — компиляция src → dist, потом `node dist/index.js`.

5. **Почему null нельзя присвоить переменной типа string при strictNullChecks? Как правильно это сделать?**
   При strictNullChecks null — отдельный тип, который не входит в string. Правильно: `let name: string | null = null;`

6. **Чем void отличается от undefined в контексте возвращаемого типа функции?**
   void — «функция ничего не возвращает» (значение не важно, обычно побочные эффекты). undefined — конкретное значение, функция с таким типом обязана вернуть именно `undefined` явно.

7. **Какую роль играют опции rootDir и outDir в tsconfig.json?**
   rootDir — откуда берутся исходники, outDir — куда складывается скомпилированный JS. Структура папок в dist повторяет структуру src.
